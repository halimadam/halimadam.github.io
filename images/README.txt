Put your pictures in this folder.
Then write the file name in content.js, for example:  "images/talks/eoin-1.jpg"

Tips
- Use .jpg or .png. Keep each picture under about 1 MB so the site loads fast.
- Use simple file names: lowercase, no spaces (eoin-1.jpg, not "Eoin Talk (1).JPG").
- Your portrait: save it as images/photo.jpg, then set  photo: "images/photo.jpg"  in content.js.
  A portrait taller than wide (4 by 5) fits the frame best.
